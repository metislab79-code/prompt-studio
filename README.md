# 행정문서 프롬프트 스튜디오

중앙행정기관·지방자치단체·공공기관의 보고·홍보 담당자를 위한 **실습용 프롬프트 빌더**입니다.
쓰려는 문서를 고르고 내 상황을 입력하면, 국립국어원 공공언어 기준을 반영한 생성형 AI 프롬프트가 완성됩니다.
복사해서 ChatGPT·Gemini·Claude 등에 붙여 넣어 사용합니다.

- 제작: 메티스경영연구소 Metis Lab
- 문의: ceo@metislab.co.kr

## 바로 쓰기

`index.html` 파일 하나로 동작합니다. 서버·설치·인터넷 연결이 필요 없습니다(글꼴·로고 내장).

1. `index.html`을 브라우저(Chrome·Edge·Whale 등)로 엽니다.
2. 홈에서 쓸 문서를 누릅니다.
3. 칸에 맞춰 내 상황을 적거나 **예시 상황 채우기**로 체험합니다.
4. **프롬프트 복사**를 눌러 AI 대화창에 붙여 넣습니다.

## GitHub Pages로 공개하기

1. 이 폴더의 파일을 저장소 최상위에 올립니다(`index.html`, `README.md`, `FONT-LICENSE.txt`, `.nojekyll`).
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 지정합니다.
3. 잠시 뒤 `https://<계정명>.github.io/<저장소명>/` 주소로 열립니다.

> 프롬프트 복사 버튼은 https 주소(GitHub Pages 포함)나 내 PC에서 연 파일에서 동작합니다.

## 구성

| 구분 | 내용 |
|---|---|
| 홍보·대외 문서 | 보도자료(국립국어원 길잡이 8유형·사진 보도자료), 브리핑·위기대응, 오보 대응·설명자료, 이메일·업무 메시지, 말씀자료(축사) |
| 공문·업무 규정 | 공문(기안문), 공문 교정, 업무 규정 확인 |
| 보고 문서 | 검토보고서, 정책보고서, 회의록, 보고서 다듬기(개조식·원 페이지·서술형) |
| 참고 도구 | 공공언어 자가 점검, 쉬운 우리말 사전, 보고서 실무 노트, 홍보·행사 실무 노트, 보도자료 유형 8가지, 보도자료 형식 기준, 구성과 작성 원칙, 프롬프트 해부·운영안, 국립국어원 바로가기 |

모든 프롬프트는 8개 블록(역할·맥락·입력 자료·작성 원칙·출력 형식·추가 산출물·셀프 점검·안전장치)으로 조립되며,
맥락 블록에 외부 환경(정책·경제·사회문화·기술·환경·평판) 고려 지시가 들어갑니다.

## 개인정보와 보안

- 입력한 내용은 브라우저 밖으로 전송되지 않습니다. 이 페이지는 AI를 직접 호출하지 않고 프롬프트만 만듭니다.
- 일반 주민·민원인의 실명·주민등록번호·연락처는 입력하지 말고 ○○○으로 가리세요. 휴대전화·주민등록번호 형식이 입력되면 경고가 표시됩니다.
- AI가 만든 결과물은 초안입니다. 사실관계와 법령은 소관 부서와 원문으로 확인하고, 최종 판단과 책임은 담당자에게 있습니다.
- 예시 사례는 모두 수업용 가상 사례입니다.
